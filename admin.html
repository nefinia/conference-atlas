Organiser page

Use this page to post announcements and move or cancel talks while the conference runs. There are two ways to use it.

Without a server (simplest)

Write your announcements and changes here, then download a small file called live.json and upload it to your website, in the same folder as index.html. Phones pick it up within a few minutes. Nothing else is needed. This works for any conference.

With a server. If you set up the optional server (see docs/worker-setup.md), you can publish with one button and no upload. You also get the private feedback, the board moderation and the numbers. Fill in the three boxes below.

No key yet? It writes a long random key in the box above. Copy it into a password manager, then give it to the server once: npx wrangler secret put ADMIN_KEY and paste it when asked.
